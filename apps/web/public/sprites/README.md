# Agent sprites

Drop a PNG in here named exactly `<role>.png` and it shows up automatically in the
Tier B office view — no code changes needed. Falls back to the Tier A icon/color badge for
any role without a file.

Valid role slugs:

```
orchestrator.png
product.png
architect.png
backend.png
frontend.png
qa.png
docs.png
researcher.png
designer.png
devops.png
security.png
growth.png
support.png
```

Any size works but square-ish, transparent-background pixel art reads best against the
room panels.
